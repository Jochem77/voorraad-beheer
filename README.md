# Voorraad Beheer

Een eenvoudige voorraad management app om controllers, consoles en accessoires bij te houden.

## Features

- ✅ Artikelen toevoegen (controllers, consoles, accessoires)
- ✅ Status bijhouden (onbekend, niet te maken, getest, verkocht)
- ✅ Hoeveelheid beheren
- ✅ Artikelen verwijderen
- ✅ Responsive design

## Status Opties

- **Onbekend**: Status is nog niet bepaald
- **Niet te maken**: Artikel kan niet gerepareerd/geconfigureerd worden
- **Getest**: Artikel is getest en werkt goed
- **Verkocht**: Artikel is verkocht

## Setup

```bash
# Dependencies installeren
npm install

# Dev server starten
npm run dev

# Build voor productie
npm run build
```

## Technologie

- React 18
- TypeScript
- Vite
- CSS3
